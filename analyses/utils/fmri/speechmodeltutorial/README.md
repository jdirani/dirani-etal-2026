# Speech Model Tutorial Utilities

The files in this folder are taken from the [Speech Model Tutorial](https://github.com/HuthLab/speechmodeltutorial/tree/master) repository by the Huth Lab (UT Austin).

Only the three files required by the analyses in this repository are included:
- `interpdata.py`
- `ridge.py`
- `util.py`

Please refer to the original repository for the full tutorial, documentation, and citation.
